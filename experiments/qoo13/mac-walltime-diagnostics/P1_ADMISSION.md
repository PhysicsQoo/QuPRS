# QOO-13 P1 — offline Mac environment admission screening

This **does not** run CodSpeed, GPMC, QuPRS, macOS commands, or a benchmark. It analyzes an **existing** `p1-monitor.json` generated by `qoo13_mac_diagnostics.py`. It does not amend or overwrite any original evidence. It never outputs an A/A performance `PASS` or grants permission to run A/A / ABBA.

Codex must use the existing actual Mac evidence path; this public branch intentionally stores no private absolute paths. Avoid touching the dirty main worktree. Run these commands in the dedicated experiment-branch worktree, with no background tasks stopped, no timed measurements, and no uploads.

## Screening policy (provisional, not calibrated)

- **ABSTAIN** when any sample has CPU idle below 50%, `backupd` CPU greater than 100%, or another listed single process greater than 100%. This is a conservative pilot stop rule, not a scientific performance gate. On the historical seven-sample Mac pilot, three idle values below 50% require `ABSTAIN` regardless of `backupd=0`.
- **INCOMPLETE** when no stop rule fired but there are fewer than seven samples, less than 25 seconds between first and last sample, missing/invalid CPU idle, process list, monotonic time, or swap-in/out counters.
- **QUIET_CANDIDATE_ONLY_NOT_CERTIFIED** when sufficient evidence shows no observed stop rule. This is **not** an A/A admission pass. Thermal readings that merely say no status has been recorded are unavailable. Even numeric CPU-limit readings cannot certify absence of throttling. A 30-second window cannot establish long-term stability.
- Swap-in/out rates are **reported, not gated**, because there is no validated swap-rate threshold. A high cumulative swap allocation is not itself the observed swap activity rate.

All verdicts retain `PERFORMANCE_UNQUALIFIED / PRECISION_UNVERIFIED`, `authorizes_benchmark=false`, and require human evaluation of a future naturally quiet window before any independently scoped A/A. Historic A1 (576.188 ms) and the earlier smoke (593.73 ms) are not a valid A/A series and must not be pooled.

## Verification / caveats

The standalone assessment uses only Python's standard library and a bounded input (maximum 8 MiB) and records its SHA-256. It requires an existing regular file, refuses symlink input, and uses exclusive-file creation for a new output path. It reads the JSON report but does not copy sensitive process or host details into the classification output. The threshold is a temporary heuristic based on previous QOO-13 stop rules; refine it only after evidence from a controlled design, not to force an A/A to pass. Do not use its output as a CodSpeed benchmark metric.

Offline synthetic tests cover the prior `backupd` and 3/7 low-idle conditions, other high-CPU processes, incomplete data, counter resets, quiet-but-unqualified candidates, invalid sources, and output protection. Linux-container test PASS is not macOS host validation.
