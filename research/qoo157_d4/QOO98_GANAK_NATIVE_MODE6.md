# QOO-98 — native pinned Ganak 2.8.0 Mode6 print-resolution gate

Source audit: [GANAK_MODE6_PINNED_PRECISION_SCOPE.md](GANAK_MODE6_PINNED_PRECISION_SCOPE.md). This independent scientific experiment runs the **unchanged official** Linux x86_64 Ganak release, verifies both tarball and extracted executable SHA256 against QuPRS's committed `ganak-release.txt`, and verifies the embedded Ganak SHA `b4ca02f78301aadeb7fa9acb5ed1524dc3fa0281`.

It exercises `--mode=6 --mpfrprec=127` on the **exact original QuPRS weighted CNF SHA** for Grover4 EQ, QAOA7 NEQ, QPE exact8 EQ and QFT16 EQ. It separately probes 127/256 requested bits on **seven exact small Fraction-complex model-count oracles**: negative real/imaginary weights, unconstrained weighted sum, positive/negative equivalence, near-cancellation, complete cancellation and unweighted free choice. The independent small oracle enumerates Boolean assignments and multiplies complex rational weights exactly.

The source Mode6 `mpfr_printf("%.8Re + %.8Rei")` contract yields only **nine significant printed decimal digits**, regardless of requested precision. Parse the strict native format and compute printed half-unit `5 × 10^(exponent-9)` for each component; small exact oracles must fall inside the textual rounding interval. For large CNFs the original archived **GPMC38 approximate numeric result** is not an exact oracle, so maintain its separate historic `1e-12 × count-scale` screening allowance in addition to the actual Ganak print half-unit. This addition is **not a certificate of Ganak internal arithmetic error**.

**Even if every print-count screen passes, the admitted result is** `NATIVE_PRINT_SCREEN_PASS_PRECISION_LIMITED`, accompanied by `NOT_COMPARABLE_FOR_38D_OUTPUT`. Neither the `exact` word in Ganak output nor a 127-bit request makes the final printed 9-digit count a 38-digit oracle. Any cancellation-derived zero count must be recorded independently of the binary SAT-status line. Failures, including count discrepancies or mismatched pins, remain evidence, not silently accepted. No benchmarks, solver patches, routine main/dev CI changes or solver default change.

The CI is [QOO98 native source-pinned admission](../../.github/workflows/qoo98-ganak-pinned-mode6-native.yml), an isolated experiment only.
